# כיוון מסך

אפליקציית Android קטנה ונקייה להוספת אריח **„כיוון מסך”** לחלונית ההגדרות המהירות.

## מה יש באפליקציה
- אריח Quick Settings בשם „כיוון מסך”.
- לחיצה על האריח מחליפה בין אוטומטי, אנכי, אופקי, אנכי הפוך ואופקי הפוך.
- לחיצה ארוכה על האריח פותחת מסך בחירה מלא וברור.
- אם נדרשת הרשאת שינוי הגדרות מערכת, האפליקציה מובילה למסך ההרשאה המתאים.
- ממשק RTL מודרני ופשוט.

## בנייה
הפרויקט מיועד ל-Android עם Gradle/AGP ומוכן לבנייה דרך GitHub Actions.
